# Included background video

`background.mp4` is an unchanged copy of the supplied SaveClip MP4; the original upload is also preserved here. The video is approximately 9 seconds long, portrait 720 × 1280, and configured in `mediaConfig.backgroundVideo` in `script.js`.

The website requests muted, looping, inline playback behind a rose-tinted veil. It pauses when animations are paused, reduced motion is enabled, or the tab is hidden. If playback is unavailable, the static rose-paper background remains usable.

To replace it, add one permitted browser-friendly video and update the local configuration path. No Instagram credentials or remote media links are needed. Nothing has been published.
